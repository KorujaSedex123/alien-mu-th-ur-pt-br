## ✨ Features Breakdown

### 🛠️ Base Module Features (Developed by ShazProd)
*   📟 **Analogue CRT Aesthetics**: Heavy CRT scanlines, typewriter typing effects, brightness flickering, and synchronized visual glitch effects.
*   👁️ **Mirror Spectator Mode**: Players can watch the active operator's terminal in real-time, sharing the exact same text stream and terminal glitches!
*   🔌 **Dynamic Hacking Protocol**: Typing `HACK` launches a security bypass request. The Game Master (GM) gets an interactive pop-up to instantly approve or deny the hack.
*   🚨 **CERBERUS Protocol**: Nuclear self-destruct countdown with full-screen red warning loops, sirens, and automatic session logout upon detonation.
*   🎮 **Environmental Controls**: GM-approved terminal commands to lock/unlock doors, control lighting (`LIGHTS DIM/SHUTDOWN`), vent gas, or operate cryogenic pods.

### 🇧🇷 Custom Fork Features (Added by KorujaSedex123)
*   🌐 **100% Brazilian Portuguese Localization**: Complete translation mapped directly to the official terminology of Editora New Order's Alien RPG books (Stress, Panic, Special Orders).
*   ⚙️ **Dynamic Custom GM Commands**: GMs can register their own terminal prompts and responses (such as hidden clues, lore secrets, or corporate directives) directly via the Foundry VTT Module Settings menu in a simple JSON format—**no code editing required!**

## 🚀 Quick Installation

To install this custom edition of the module in your Foundry VTT (v14 recommended):

1.  In the Foundry VTT main setup screen, navigate to **Add-on Modules**.
2.  Click **Install Module**.
3.  In the **Manifest URL** field, paste the link below:
    ```
    https://github.com/KorujaSedex123/alien-mu-th-ur-pt-br/releases/latest/download/module.json
    ```
4.  Click **Install** and wait for the process to complete.
5.  Enable the module in your world settings under **Manage Modules**.
