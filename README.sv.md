#### ✨ Sammanställning av Funktioner / Features Breakdown
##### 🛠️ Funktioner i Grundmodulen (Utvecklad av ShazProd)
*  📟 **Analog CRT-estetik**: Kraftfulla CRT-sveplinjer, skrivmaskins-skriveffekter, flimrande ljusstyrka och synkroniserade visuella glitch-effekter.
*  👁️ **Spegling av Åskådarläge**: Spelare kan följa den aktiva operatörens terminal i realtid och dela exakt samma textström och terminalstörningar!
*  🔌 **Dynamiskt Hackningsprotokoll**: Skriv HACK för att initiera en begäran om säkerhetsförbikoppling. Spelledaren (GM) får en interaktiv popup för att direkt godkänna eller neka hacket.
*  🚨 **CERBERUS-protokoll**: Kärnvapensjälvförstörelseneträkning med röda varningsslingor i helskärm, sirener och automatisk utloggning av sessionen vid detonation.
*  🎮 **Miljöreglage**: Spelledargodkända terminalkommando för att låsa/låsa upp dörrar, styra belysning (LIGHTS DIM/SHUTDOWN), vädra ut gas eller styra kryogena kapsler.

##### 🇧🇷 Funktioner i Anpassad Fork (Tillagd av KorujaSedex123)
*  🌐 **100% Brasiliansk Portugisisk Lokalisering**: Komplett översättning mappad direkt till den officiella terminologin i Editora New Orders Alien RPG-böker (Stress, Panik, Specialorder).
*  ⚙️ **Dynamiska Anpassade Spelledarkommandon**: Spelledare kan registrera egna terminalprompter och svar (som dolda ledtrådar, lore-hemligheter eller företagsdirektiv) direkt via inställningsmenyn för Foundry VTT-modulen i ett enkelt JSON-format—**ingen kodredigering krävs!**

#### 🚀 Snabbinstallation / Quick Installation
För att installera denna anpassade version av modulen i din Foundry VTT (v14 rekommenderas):
1. I huvudmenyn för inställningar i Foundry VTT, navigera till **Add-on Modules**.
2. Klicka på **Install Module**.
3. I fältet **Manifest URL**, klistra in länken nedan:
4. Klicka på **Install** och vänta på att processen slutförs.
5. Aktivera modulen i dina världsinställningar under **Manage Modules**.
